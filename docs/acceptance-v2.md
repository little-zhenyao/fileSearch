后端共 75 个回归用例通过。TypeScript 检查及 Vite 正式构建通过。前端状态拆分为搜索和工作台导航模块，阅读器通过阅读区 ID、持久位置及位置回调接入。本轮多 agent 检查与新增缺陷回归见 [V2 缺陷检查记录](v2-bug-audit.md)。

V2 浏览器回归包含十组流程；新增统计接口连续失败时资料仍可加载、空分类提示与清除筛选、资料列表接口失败后的错误提示与重试、导入后清除原分类并显示所属课程资料。实际应用外部请求数为 0，浏览器运行错误数为 0。应用的本地 CSP、访问来源校验与写请求头限制继续保留。

## 资料显示与统计修复

- 正式库只读核对：IS1128 共 10 份资料，均为 Lecture；Summary 分类下的 0 份是筛选结果。各分类增加数量，空分类改为明确筛选提示并提供“显示所有资料”；导入提交后显示所属课程的全部资料，任务尚未完成时提供进度入口。
- `/api/stats` 对每个文件仅取一次状态，忽略遍历后消失的文件，避免 SQLite 清理 `-shm`、`-wal` 时触发 `FileNotFoundError`。两项后端回归覆盖消失文件与统计接口连续访问。
- 前端各接口独立更新；统计失败不会阻断资料、课程和任务刷新，也不会反复弹提示。统计暂不可用时，资料数量仍来自已加载列表；列表加载失败显示错误与重试入口，不再伪装成空库。

## 性能结果

100 份文本型 PDF，每份 30 页，共 3000 页，每页约 1900 个字符。API 每种查询重复 20 次，预建索引与热缓存；首次合成索引构建约 39.16 秒。

| API 查询 | 模式 | P95 |
|---|---|---:|
| deadlock | 全部词 | 68.50 ms |
| mutual exclusion | 完整短语 | 76.08 ms |
| deadlock circular | 全部词 | 99.37 ms |
| deadlock nonexistent | 任一词 | 91.26 ms |
| lecture042page017 | 全部词 | 1.40 ms |
| 不存在 | 中文连续字串 | 1.29 ms |

浏览器使用同一个 100 文件、3000 页合成资料库，1440×1000 视口；每项 20 次，单独运行以避免其他浏览器回归并行影响计时。打开耗时从点击结果到目标文件标题、可见高亮及 PDF 文字层均出现。

| 浏览器操作 | P95 | 目标 |
|---|---:|---:|
| 提交搜索到结果可见 | 191 ms | ≤1000 ms |
| 单栏点击结果到可阅读且高亮 | 126 ms | ≤2000 ms |
| 保留另一栏时打开结果 | 124 ms | ≤2000 ms |

上述结果是当前设备的合成资料测量，不代表所有真实课件的性能或定位准确率。

## 重现方式

后端：`.venv/bin/python -m pytest -q`。前端：在 `frontend` 运行 `pnpm build`。依赖与 PDF 运行资源均沿用现有锁定版本，没有新增运行时联网服务。

浏览器脚本需要可用的 Node、Playwright 和 Chrome。仅使用明确指定的独立测试资料库；不要指向个人正式资料库。

```bash
# 项目根目录；生成 V2 的两份 PDF 与两份 DOCX 样本
.venv/bin/python scripts/make_v2_samples.py

# 独立测试服务，另开终端运行下面的浏览器脚本
FILESEARCH_CONFIG="$PWD/.local/v2-qa/settings.json" .venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8767 --no-access-log

# 环境中需能解析 playwright；按实际 Node 安装路径配置 NODE_PATH
FILESEARCH_TEST_URL=http://127.0.0.1:8767 FILESEARCH_TEST_LIBRARY="$PWD/.local/v2-qa/library" node scripts/browser_v2.cjs

# 建立独立的 100 文件、3000 页性能库并测量 API
.venv/bin/python scripts/benchmark.py --root .local/v2-benchmark/library --runs 20
```

浏览器性能脚本为 `scripts/browser_performance.cjs`。先让独立服务的 `FILESEARCH_CONFIG` 指向一个包含 `library_path` 的 JSON 文件，资料库设为 `.local/v2-benchmark/library`；在端口 8768 启动后，以同样的 `FILESEARCH_TEST_URL` 和 `FILESEARCH_TEST_LIBRARY` 环境变量运行该脚本。脚本会验证所连接资料库与指定目录完全一致。

生成报告与截图位于 `.local/v2-qa/browser`、`.local/v2-qa/v1-smoke`、`.local/v2-benchmark/benchmark-report.json` 和 `.local/v2-benchmark/browser-performance.json`，均为可重现的本地验收产物，不属于源码或运行依赖。

## 使用前仍需完成

- 尚未使用 10–20 份真实课程资料建立固定的已知命中集。需抽检多栏顺序、公式附近文字、嵌入字体、断词、表格和长文档，发现检索或定位问题时优先修复。
- 自动化通过拦截所有外部请求验证网络独立性；没有自动关闭用户系统网络。仍需在目标 Mac 上物理断网完成启动、查询、双栏、收藏和退出重启的一轮演练。
- 沿用 V1 的 PDF 文字层与 DOCX 结构化预览边界；未承诺扫描文字 OCR、Word 原生页码、公式语义或复杂版式保真。
- 自动增量更新、页面缩略图、OCR、语义搜索、自动答案、Cheatsheet、Windows 和独立安装包均不在本轮交付范围。

正式资料库将在用户下一次启动 V2 时自动备份并迁移。若旧服务仍运行，先停止再启动，避免复用仍在内存中的 V1 后端。回退方法与备份位置见 README。
