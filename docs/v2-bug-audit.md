## 重现

使用 `docs/acceptance-v2.md` 中的独立测试服务配置与 Node/Playwright 环境。先运行 `scripts/browser_v2.cjs` 建立合成课件，再依次执行新增两个浏览器脚本。三个脚本均通过 `FILESEARCH_TEST_URL` 指定本地服务，并要求 `FILESEARCH_TEST_LIBRARY` 与服务实际资料库路径一致。

本轮覆盖合成文件和可控的响应乱序，没有建立真实课件的完整已知命中集，也未执行物理断网演练或重新测量 3000 页性能。通过这些检查不代表已经排除所有缺陷。
